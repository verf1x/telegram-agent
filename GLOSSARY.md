# Telegram-бот для взаимодействия с Codex

Приватный бот для независимого общения одобренных пользователей с Codex в личных чатах Telegram.

## Термины

**Владелец**:
Администратор бота, который лично одобряет пользователей и управляет их доступом.

**Одобренный пользователь**:
Пользователь Telegram, которому владелец разрешил общение с Codex через бота.

**Список доступа**:
Перечень пользователей, которым владелец разрешил общение с агентом. Включение и исключение пользователей выполняет сам владелец, без заявок пользователей.

**Диалог**:
Последовательность сообщений пользователя и ответов Codex с общим контекстом. Диалоги независимы друг от друга, в том числе у одного пользователя: история, вложения и файлы ответа одного диалога недоступны в другом.
_Не использовать_: чат Telegram как синоним диалога.

**Топик**:
Отдельная тема в интерфейсе личного чата Telegram с ботом, предназначенная для независимого диалога пользователя с Codex.
_Не использовать_: чат Telegram как синоним топика.

**Сброс диалога**:
Начало нового диалога в текущем топике с удалением сохранённого контекста и материалов предыдущего. Топик, его название и сообщения, уже доставленные в Telegram, сохраняются.

**Удаление топика**:
Удаление темы вместе с её сообщениями из Telegram. При удалении через бота также очищаются сохранённый контекст и материалы соответствующего диалога.

**Отзыв доступа**:
Решение владельца, прекращающее право пользователя общаться с агентом через бота. Сам по себе отзыв доступа не означает удаления сохранённого диалога.

**Текстовая версия ответа**:
Читаемое текстовое представление ответа агента, доступное как альтернатива основному ответу с оформленными формулами и таблицами.

**Вложение**:
Фото или файл, отправленный пользователем как материал для задания. Вложения принадлежат только диалогу отправившего их пользователя.

**Задание**:
Текстовое обращение к агенту, которое может включать несколько вложений. Текст задания передаётся в подписи к материалам или отдельным сообщением после них.

**Ожидающие вложения**:
Материалы, уже отправленные пользователем, для которых ещё не получен текст задания.

**Генерация изображений**:
Создание изображений по описанию пользователя, при необходимости с учётом образцов из его диалога. Результат передаётся пользователю как изображение в том же чате.
