# Проект

Telegram-бот для взаимодействия с Codex. Требования заказчика описаны в `task.md`.

## Agent skills

- Используй проектные навыки из `.agents/skills/`, следуя соответствующему `SKILL.md`.
- Задачи и спецификации ведутся в GitHub Issues через `gh`: `docs/agents/issue-tracker.md`.
- Для triage используй метки из `docs/agents/triage-labels.md`.
- Перед работой с доменными терминами и решениями читай `GLOSSARY.md` и относящиеся к задаче ADR по правилам `docs/agents/domain.md`.
