# Восстановление создания PDF — issue #16

Проверено 14 ноября 2026 года с Codex CLI 0.169.0 и настоящей изолированной средой документов.

## Причины отказа

Рабочий процесс использовал сборку без реализации файлов ответа, хотя исходники уже содержали её. Проверка `CodexEngine` из `dist` обнаружила отсутствие `isolated_workspace` и `export_files` в доступных возможностях.

После пересборки обнаружен отдельный сбой старых диалогов: передача `developerInstructions` в `thread/resume` не обновляет исходное сообщение инструкций в истории модели. Реальный Codex в таком диалоге снова отказался создавать PDF, не вызвав экспорт.

## Исправление

- `npm start` запускает сборку перед приложением. Ошибка сборки прекращает запуск.
- После возобновления native thread бот добавляет актуальные инструкции и список материалов через `thread/inject_items` как сообщение разработчика. Старые диалоги используют существующий JSON-адаптер `isolated_compute`; история и идентификатор диалога сохраняются.
- Рабочий бот пересобран и перезапущен после проверки отсутствия активных заданий.

## Проверка

Регрессионный тест воспроизводит сохранение старых инструкций при возобновлении. До исправления он падал на отсутствии `isolated_workspace`; после исправления проверяет возможности создания и экспорта, актуальный путь сохранённого PDF и сохранение идентификатора диалога.

Настоящий Codex создал и экспортировал `pdf-check.pdf` в новом диалоге и в старом native thread, имевшем только `isolated_compute` и прежние инструкции. До исправления старый thread отказывался создавать файл; после исправления тот же thread экспортировал PDF размером 1393 байта. Независимый `pypdf` внутри изолированной среды подтвердил доступные для поиска текст `PDF_REGRESSION_OK` и формулу с результатом `42` в обоих документах.

Проверка использовала отдельные временные диалоги; тестовые сообщения в Telegram не отправлялись. Отправка исходных байтов PDF через `sendDocument`, маршрутизация по топикам и восстановление доставки проверяются тестами проекта.

```sh
VERFIX_TEST_PYTHON="$PWD/.venv/bin/python" VERFIX_TEST_FILES=1 npm test
npm run check
npm run prestart
git diff --check
```

Результат: **176/176 тестов, без пропусков**, проверка типов, сборка и проверка diff прошли.
