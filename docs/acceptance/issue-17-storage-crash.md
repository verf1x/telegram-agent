# Остановка бота на чтении состояния — issue #17

17 ноября 2026 года пользователь сообщил о недоступности бота. Сохранённый PID отсутствовал. Последний аварийный журнал содержит SyntaxError из JSON.parse в SqliteStore.all(), вызванном периодическим BotController.resume(). Исключение фонового таймера завершило Node.js; стандартный вывод исключения включил исходную строку состояния.

До изменений создана согласованная приватная резервная копия SQLite. Проверка целостности базы успешна; все текущие состояния разбираются, 80 повторных чтений прошли. Структурный символ в аварийной строке отличается от сохранённого состояния. Первичный источник этого искажения не установлен; повреждение сохранённой базы не подтверждено. Исходные журналы сохранены в приватном каталоге диагностики. История и материалы не сбрасывались.

Исправление ограничено обработкой ошибок:

- Разбор сохранённого состояния возвращает безопасную ошибку без исходной строки и вложенного SyntaxError.
- Ошибки периодического восстановления, обработчика изменения конфигурации и таймера альбомов перехватываются; повторные одинаковые сообщения ограничены.
- Следующая попытка повторяет также незавершённое применение конфигурации, включая отзыв доступа и планирование альбомов.
- Текст задания альбома сохраняется до успешной записи запроса; ошибка чтения другого диалога не уничтожает подпись.
- Остановка процесса освобождает таймеры и запросы без чтения состояний из базы.

Минимальный дочерний процесс с синтетической некорректной записью до исправления завершался с SyntaxError и печатал контрольный маркер. После исправления он остаётся жив, завершается штатно и не печатает маркер. Проверки охватывают неисправленное состояние, восстановление доставки после успешного чтения, повторное применение отзыва доступа, повторную обработку альбома и сохранение непустого задания альбома при ошибке другого диалога. Модель и Telegram в этих сценариях заменены тестовыми адаптерами; рабочие пользовательские данные в тесты не включены.

```sh
node --test tests/store.test.ts tests/bot.test.ts
VERFIX_TEST_PYTHON="$PWD/.venv/bin/python" VERFIX_TEST_FILES=1 npm test
npm run check
npm run build
git diff --check
```

Финальный результат полного прогона: **178/178 тестов, без пропусков**; typecheck, сборка и diff check прошли.

Standards/Spec: замечания о повторе конфигурации и сохранении подписей исправлены. Повторное ревью оставшихся конкретных дефектов не выявило.

Рабочий бот запущен в фоне с существующей базой и актуальной сборкой. Это исправление подтверждённого механизма падения, а не установленная причина появления повреждённого символа.
