# Метки triage

| Роль в навыках Matt Pocock | Метка GitHub | Значение |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Нужно оценить входящую задачу |
| `needs-info` | `needs-info` | Ожидается дополнительная информация |
| `ready-for-agent` | `ready-for-agent` | Задача достаточно описана для агента |
| `ready-for-human` | `ready-for-human` | Требуется работа человека |
| `wontfix` | `wontfix` | Задача не будет выполнена |

Если навык указывает triage-роль, используй соответствующую метку из этой таблицы.
