# Доменные документы

Правила чтения доменной документации для инженерных навыков.

## Перед изучением кода

- Прочитай `GLOSSARY.md` в корне, если он существует.
- Прочитай относящиеся к задаче решения в `docs/adr/`, если каталог существует.
- Если этих файлов пока нет, продолжай без предупреждений. Навык `domain-modeling` создаёт их, когда термины или решения будут согласованы.

Используй термины из словаря в задачах, предложениях, тестах и документации. Если новое понятие ещё не определено, отметь это для `domain-modeling`.

Если предлагаемая работа противоречит ADR, явно сообщи об этом, не переопределяя решение молча.

## Структура

Это single-context проект: общий `GLOSSARY.md` в корне и ADR в `docs/adr/`.
