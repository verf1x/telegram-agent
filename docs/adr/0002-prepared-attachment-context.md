# Вложения передаются как подготовленный контекст

Пользователь разрешил чтение присланных фото и документов, сохранив запрет на доступ к файлам компьютера владельца. Поэтому документы и изображения разбираются внутри изолированной среды: ей доступен только фиксированный входной файл, подключённый только для чтения. Имена из Telegram не определяют пути на компьютере.

До получения задания в SQLite сохраняются ссылки Telegram на ожидающие вложения. После успешной обработки в истории текущего диалога сохраняются извлечённый текст и нормализованные изображения; Codex получает изображения через native image input. Это увеличивает размер локального контекста, но позволяет восстановить материалы после прерывания thread без доступа к исходным файлам на хосте и без зависимости от повторной загрузки из Telegram. Объём такого контекста ограничен, `/new` удаляет его вместе с диалогом.

Неподдерживаемое содержимое документов должно приводить к явной ошибке с предложением отправить PDF. Молчаливое исключение вложений или искажение формул при подготовке недопустимо.
