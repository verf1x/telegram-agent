# Вычисления агента только во временной изолированной среде

Владелец включил в MVP вычисления и создание изображений собственными скриптами агента, хотя исходное ТЗ относило выполнение кода к последующим этапам. Выполнение допускается только во временной изолированной среде без доступа к личным файлам владельца и данным других пользователей.

Python выполняется в bubblewrap с отдельными пространствами пользователей и процессов, подготовленной средой только для чтения и ограниченными tmpfs. Сеть, создание процессов, изменение пространств имён и создание произвольных файлов блокируются seccomp; для графиков и временных данных заранее выделены фиксированные файлы. Это позволяет ограничить также количество файлов, поскольку одного ограничения объёма tmpfs недостаточно для ограничения памяти, занимаемой inode. Проверенные PNG возвращаются доверенному процессу в виде байтов, без чтения выбранных агентом путей на компьютере владельца.

Codex работает отдельно как доверенный процесс с приватным хранилищем авторизации и диалогов. Нативные возможности ограничены профилем разрешений, отключёнными интеграциями и пустым списком execution environments: запрет доступа не опирается на инструкции модели. Проверки через бота подтвердили отказ при обращении к контрольному файлу вне среды, отсутствие Node.js filesystem-доступа и пустой набор MCP-ресурсов.
