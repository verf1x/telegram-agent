# Вычисления агента только во временной изолированной среде

Владелец включил в MVP вычисления и создание изображений собственными скриптами агента, хотя исходное ТЗ относило выполнение кода к последующим этапам. Выполнение команд допускается только во временной изолированной среде без доступа к личным файлам владельца и данным других пользователей: прямой запуск на компьютере владельца не соответствует согласованной границе доступа. Среда должна позволять агенту создавать скрипты и временные результаты; конкретный механизм изоляции ещё не выбран и требует проверки.
