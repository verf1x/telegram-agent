# Генерация изображений через встроенный инструмент Codex

Художественные изображения создаёт встроенный инструмент Codex с текущей ChatGPT-авторизацией и её лимитами. Он доступен всем одобренным пользователям в существующих диалогах; Python остаётся инструментом вычислений и научных графиков. Отдельный API key и автоматический переход на другую оплату не используются.

Доверенный процесс Codex может сохранять собственные результаты в приватном хранилище диалога, но бот принимает только ограниченные и проверенные PNG-байты native completion и никогда не читает `savedPath`. Execution environments остаются пустыми: в установленной версии Codex это блокирует локальные `referenced_image_paths` до загрузки файлов. Для редактирования инструмент получает последние изображения текущего диалога через `num_last_images_to_include`. Доступ к shell, интеграциям и файлам компьютера владельца не расширяется.

При частичном сбое готовые проверенные изображения доставляются вместе с объяснением и сообщением об ошибке. Отмена запроса или отзыв доступа прекращают доставку по прежним правилам.
