# Независимые диалоги в личных топиках Telegram

Каждый топик личного чата с ботом содержит независимый диалог: история, вложения и файлы ответа недоступны из других топиков, в том числе принадлежащих тому же пользователю. Создание и переименование тем выполняются штатными средствами Telegram; существующий контекст сохраняется для продолжения в отдельном топике «Предыдущий диалог», а новые темы получают пустой контекст. Уже доставленные сообщения прежнего диалога остаются на прежнем месте в Telegram и не дублируются в новом топике.

Для гарантированной очистки данных бота пользователь вызывает `/delete` в нужном топике и подтверждает действие: бот удаляет тему с сообщениями и очищает её сохранённый контекст и материалы. Штатное удаление темы пользователем остаётся доступным, но немедленная очистка данных бота при нём не гарантируется: [Telegram Bot API](https://core.telegram.org/bots/api#update) не предоставляет уведомления об удалении обычного топика.

Команда `/new` сбрасывает только диалог текущего топика и его сохранённые материалы; сам топик, название и уже доставленные сообщения остаются. Если в теме выполняется задание, `/new` или подтверждённый `/delete` останавливает его перед сбросом или удалением; поздние результаты отменённого задания пользователю не отправляются, другие топики продолжают работать.

В разных топиках одного пользователя задания могут выполняться параллельно, при этом в каждом топике выполняется не более одного задания и сохраняется общий предел нагрузки бота. Очереди заданий нет: при повторном запросе в занятой теме бот сообщает о занятости и просит повторить запрос после ответа. Ответы и индикаторы работы направляются в соответствующий топик.

Модель выбирается отдельно для каждого топика; новая тема получает модель по умолчанию. Изменение модели не влияет на другие темы, право менять модель остаётся у владельца.

Обычное текстовое сообщение вне топиков не начинает диалог с агентом: бот предлагает открыть или создать топик. Общий контекст вне тем не создаётся.
