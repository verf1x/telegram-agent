# Восстановление подтверждённой рассылки

Подтверждённая рассылка хранится в SQLite отдельно от диалогов. Перед вызовом Telegram Bot API бот записывает начало попытки, после явного ответа сохраняет результат и при перезапуске продолжает с оставшихся получателей. Для попытки с потерянным ответом бот показывает «доставка неизвестна»: у `sendMessage` нет ключа идемпотентности, и повторная попытка могла бы доставить объявление дважды. При явном `429` Telegram сообщает время до следующей попытки в `retry_after`.
