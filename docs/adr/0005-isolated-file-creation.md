# Файлы ответа создаются инструментами агента в изолированной среде

Для создания и редактирования произвольных форматов агенту разрешены выполнение кода, запуск программ, установка необходимых библиотек и доступ в интернет внутри изолированной среды. Фиксированные шаблоны документов не покрывают требование использовать возможности обычного агента; среде доступны материалы только текущего диалога, без личных файлов владельца и данных других пользователей.

Это изменяет ADR 0001 в части запрета сети, запуска программ и создания произвольных рабочих файлов. Ограниченная среда только с Python и заранее выделенными PNG больше не определяет границы новой возможности. Изоляция должна обеспечиваться технически; разрешение исполнять программы внутри среды не расширяет права доверенного процесса Codex на компьютере владельца.

Среда документов — отдельный непривилегированный Docker-контейнер на задание: корневая система только для чтения, ограниченные tmpfs, память, CPU и число процессов. В контейнер подключаются только сохранённые файлы текущего диалога и отдельный Unix-сокет HTTP(S)-прокси. Прямой сети нет; прокси проверяет все DNS-адреса, блокирует локальные сети и адреса хоста и подключается к проверенному адресу. Docker-сокет, авторизация Codex, SQLite и домашний каталог владельца не подключаются. Экспорт читает обычные файлы только внутри /work через дескрипторы с O_NOFOLLOW и запрещает ссылки. Готовые байты и ссылка на них в задании сохраняются одной транзакцией до завершения вызова инструмента; доставка использует идентификатор файла своего пользователя. Доступный ранее isolated_compute сохраняет прежнюю вычислительную среду; для сохранённых native threads, которым app-server не позволяет заменить инструменты, он также принимает JSON-команды среды документов. ADR 0003 продолжает действовать: художественные изображения создаются встроенным инструментом Codex с текущей ChatGPT-авторизацией.
